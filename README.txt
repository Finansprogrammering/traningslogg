TRÄNINGSLOGG MVP

Innehåll:
- index.html: appens gränssnitt
- app.js: logik och lokal datalagring
- manifest.json + sw.js: gör appen installerbar/offline som PWA

Förifyllt:
Överkropp: Pull-ups, Dips, Armhävningar
Core: Toes-to-bar, Leg raises, Body saw

Funktioner:
- 5 set per övning som standard
- reps, vikt+reps eller tid
- visar föregående resultat
- historik
- lägg till egna övningar
- skapa/redigera passmallar
- export/import av all data som JSON
- fungerar offline efter installation

Nästa steg: publicera appen och koppla Google Sheets via Google Apps Script.
